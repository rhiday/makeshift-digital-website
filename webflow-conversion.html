What gets installed in your Webflow project.

A) CMS conversion fields (the control panel)

We add structured fields to your CMS collections, typically:

  • Persona (dropdown)
  • Funnel stage (TOFU/MOFU/BOFU)
  • Primary CTA type (Audit/Demo/Download/Newsletter)
  • CTA headline / button label / CTA link
  • Content upgrade title + asset link
  • Internal links + refreshed_on date

B) Templates + reusable blocks

We install conversion-ready templates and reusable blocks:

  • Blog template with CTA + upgrade block
  • Use Case template with BOFU CTA + capture block

Styled to match your design system.

C) Lead routing + attribution

Every submission includes:

  • Page title/slug
  • UTM/source
  • Key form answers (for qualification)

Then we route to Slack/Email/CRM and log it in a simple table.

Optional module: AI lead summary + scoring (in Slack)

FAQ

Do we need to rebuild the site?

No. We install the conversion layer inside your existing CMS + templates.

Do we need HubSpot or a marketing automation platform?

No. We can route to Slack/email. If you already use a CRM, we connect it.

Do we have to tag persona/stage for every CMS item?

Not necessarily. We can set defaults at the template level and only override exceptions.

Will this "guarantee leads"?

We don't promise rankings or lead volume. We install the system so your pages consistently capture and route leads with attribution.

Can AI auto-edit or auto-publish content?

We can generate drafts/suggestions, but publishing stays human-approved.
